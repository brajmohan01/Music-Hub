🎵 About – Music Hub

Music Hub is a lightweight, responsive web-based music player built as part of my learning journey through the CodeWithHarry - Sigma Web Development Course. This project helped me strengthen my skills in HTML, CSS, JavaScript, and working with local files and server-side content.

💡 Project Purpose

The primary goal of this project was to gain hands-on experience with:

  • Building a user-friendly UI with HTML & CSS
  • Using JavaScript to interact with files and media elements
  • Integrating local and server-side music sources
  • Practicing DOM manipulation and event handling

🔧 Features

  • 🎧 Play Local Files: Upload and play your own music directly in the browser
  • 🌐 Stream Server Songs: Listen to music hosted on the web server
  • ⏯️ Play, Pause, Next, Previous: Full control over playback
  • 🕒 Progress Bar & Time: Shows current and total duration
  • 📱 Responsive Design: Works on all screen sizes

⚙️ How It Works – Behind the Scenes

1. HTML Structure

Clean layout using semantic HTML. Sections for player, controls, and playlist.

2. CSS Styling

Styled using Flexbox and modern CSS for a responsive and minimal interface.

3. JavaScript Logic

  • Uses <input type="file"> and FileReader API to handle local uploads
  • Predefined server songs are loaded into an array and played on demand
  • Audio controls and UI synced using event listeners and the Audio API

4. Hosting Server Songs

Server songs are stored in a public directory (e.g., /songs/) and dynamically listed in the player.

📚 What I Learned

  • Working with the HTML5 Audio API
  • Handling local files in the browser
  • Creating interactive interfaces with JS
  • Syncing UI elements with audio playback events

👨‍💻 Tech Stack

  • HTML5
  • CSS3
  • JavaScript (Vanilla)
  • (Optional) Node.js/Express for server hosting
